Enjambres de Drones:
Modelado y Programación de rutas de
vuelo, con enjambres de drones



Descripción del Proyecto

Este proyecto introduce a los estudiantes en el diseño, programación y operación coordinada de enjambres de drones, utilizando 10 drones Crazyflie programables. El trabajo combina modelado tridimensional, programación, redes inalámbricas, sistemas de posicionamiento y electrónica, para conseguir que múltiples drones ejecuten trayectorias coordinadas dentro de un espacio controlado.

Las coreografías se diseñan en Blender, donde se construyen las formaciones y movimientos tridimensionales. Posteriormente, Skybrush Studio permite convertir el diseño en trayectorias de vuelo, realizar la planificación de movimientos, verificar las rutas y exportar el programa que será ejecutado por el enjambre.

Para posicionar los drones se utiliza el sistema Lighthouse, mediante estaciones base que permiten a los Crazyflie determinar su posición en el espacio. La comunicación entre la computadora y los drones se realiza mediante Crazyradio, mientras que la configuración de canales, direcciones y parámetros de comunicación permite gestionar la flota.

El proyecto implica también configurar el espacio de vuelo, calibrar el sistema, realizar pruebas y ajustes constantes, así como reparar drones, actualizar y flashear firmware, configurar diferentes parámetros y solucionar problemas de hardware y comunicación. El proceso experimental es fundamental para conseguir vuelos sincronizados y resultados precisos.
