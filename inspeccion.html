Inspección de cuerpos de agua:
Detección de objetos contaminantes
sobre ríos, con visión artificial



Descripción del Proyecto

Este proyecto explora el uso de drones y visión artificial para el monitoreo de ríos y otros cuerpos de agua, con el propósito de identificar objetos y residuos que puedan representar fuentes de contaminación. Los estudiantes realizan vuelos sobre zonas seleccionadas, utilizando misiones previamente planificadas mediante software especializado o vuelos a baja altura que permiten obtener imágenes y video con el nivel de detalle necesario para identificar los elementos presentes en la superficie del agua.

El material recopilado se utiliza para construir conjuntos de datos destinados al entrenamiento y validación de modelos de inteligencia artificial. Las imágenes son seleccionadas, organizadas y etiquetadas para enseñar al sistema a reconocer diferentes tipos de residuos y objetos contaminantes. Posteriormente, mediante YOLO (You Only Look Once), se entrenan modelos personalizados capaces de detectar automáticamente estos elementos en nuevas imágenes o secuencias de video.

El proyecto integra conocimientos de operación de drones, fotografía y video aéreo, procesamiento de imágenes, construcción de datasets y aprendizaje automático. Los resultados permiten explorar sistemas de monitoreo automatizado que podrían facilitar la identificación de zonas con presencia de residuos, apoyar labores de inspección ambiental y generar información para el seguimiento de las condiciones de cuerpos de agua de manera más rápida y sistemática.
