Fotogrametría: Modelos 3d
a partir de fotografía aerea



Descripción del Proyecto

Este programa introduce a los estudiantes en el uso de drones como herramienta para la captura, análisis y representación tridimensional del territorio. A través de ejercicios prácticos, los estudiantes planifican vuelos, recopilan imágenes aéreas y generan modelos digitales de diferentes espacios utilizando técnicas de fotogrametría.

Entre los proyectos desarrollados se encuentran modelos tridimensionales del campus universitario, levantamientos de áreas extensas de terreno y representaciones digitales que permiten analizar las características físicas de un espacio desde diferentes perspectivas. Para la captura de información se han utilizado drones como el DJI Mavic Pro, combinados con plataformas especializadas como DroneDeploy para la planificación de misiones, procesamiento de imágenes y generación de productos cartográficos.

El programa permite comprender el potencial de los drones para aplicaciones como levantamientos topográficos, documentación territorial, planeación, inspección y visualización de espacios, integrando conocimientos de tecnología, fotografía aérea, análisis de datos y representación digital.
